# Настройка уведомлений на PythonAnywhere (бесплатный тариф)

## 1. Настройка Scheduled Tasks

1. Зайдите на PythonAnywhere
2. Перейдите на вкладку **Tasks**
3. Нажмите **Create a new scheduled task**
4. Заполните:
   - **Command**: `cd /home/mob100500lvl/WeatherTomBot/WeatherTomBot && python3 send_notifications.py`
   - **Description**: `Weather notifications`
   - **Start at**: `00:00`
   - **Interval**: `1 hour` (каждый час)
5. Нажмите **Create**

## 2. Как это работает

- Скрипт запускается каждый час (08:00, 09:00, 10:00, ...)
- Проверяет всех пользователей с включенными уведомлениями
- Отправляет прогноз только тем, у кого время совпадает с текущим часом
- Учитывает периодичность (ежедневно, еженедельно, будни, выходные)

## 3. Ограничения бесплатного тарифа

- Максимум 1 scheduled task
- Скрипт запускается раз в час (минимальный интервал)
- Если время пользователя 08:30, уведомление придёт в 08:00

## 4. Тестирование

Запустите вручную для проверки:
cd /home/mob100500lvl/WeatherTomBot/WeatherTomBot
python3 send_notifications.py



## 5. Логи

Логи сохраняются в features.py через функцию `track()` и видны в админ-панели.
